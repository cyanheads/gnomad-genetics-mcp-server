# 0.5.1 — 2026-11-01

## Added

- **`gnomad_get_variant` QC and callsets**: `callsets.exome` and `callsets.genome` (`ac`, `an`, `af`, zygosity counts, QC `filters`; null when that callset does not carry the variant) and a `qc_status` of `pass` or `filtered` on each record ([#54](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/54)).
- **`gnomad_get_variant` `joint_populations`**: per-ancestry joint counts on `gnomad_r4`, empty on datasets without joint data ([#53](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/53)).
- **`gnomad_get_variant` `primary_transcript`**: the consequence on the gene's MANE Select transcript (its canonical one where there is none), with `is_mane_select`, `hgvsc`, `hgvsp`, and `lof` ([#57](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/57)).
- **`gnomad_list_gene_variants` columns**: `exome_filters`, `genome_filters`, `qc_status`, `transcript_id`, and `consequence_transcript` on every row and the `gene_variants` canvas table, plus a `qc_filtered` count in the output ([#54](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/54), [#57](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/57)).
- **`gnomad_list_gene_variants` `pass_only`**: opt-in input that drops rows failing QC in every callset carrying them, after `qc_filtered` counts them. Omitting it selects the same rows as before ([#54](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/54)).

## Changed

- **`gnomad_list_gene_variants` inline preview**: holds fewer rows at the same ~23 KB response size, since each row carries five more columns: 43 of the first 120 live PCSK9 rows on `gnomad_r4`, down from 76. Callers running with the canvas off, such as `.mcpb` bundle users, see only this preview.
- **`gnomad_variant_triage` and the `gnomad-genetics-guide` skill**: direct callers to check `qc_status` before reading counts as an observed frequency ([#54](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/54)).

## Fixed

- **Overall counts on `gnomad_r4`**: `ac`, `an`, `af`, and zygosity counts read gnomAD's `joint` record, where a variant carried by one callset had summed only that callset's `an`. `max_af` filters on the joint `af`. Datasets without joint data are unchanged ([#53](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/53)).
- **`oth` ancestry group**: returned on `gnomad_r3`, `gnomad_r2_1`, and `exac`, so per-ancestry counts sum to each callset's `ac` ([#55](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/55)).
- **`consequence_class`**: follows gnomAD's categories. `stop_lost` and `start_lost` move from `lof` to `missense`, as do inframe insertions and deletions (from `other`), and `transcript_amplification` moves from `lof` to `other`. Filter totals move: a `lof` filter on PCSK9 returns 204 rows on `gnomad_r4` as of November 2026, down from 213 ([#74](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/74)).
- **`gnomad_search_clinvar` placeholders**: `last_evaluated` `1/01/01 00:00` and a blank `clinical_significance` or `review_status` read as null ([#61](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/61)).
