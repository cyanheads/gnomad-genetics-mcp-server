# 0.5.0 — 2026-10-28

## Added

- **`gnomad-genetics-guide`**: Serve the gnomad-genetics-guide skill as an MCP resource for ClinVar-to-gnomAD candidate follow-up.
- **Agent Plugins 1.0.0**: root `plugin.json` and `mcp.json` provide the stdio launch configuration; Claude Code and Codex overlays forward optional server environment variables.

## Changed

- **Published guide delivery**: npm, Docker, plugins, and the Claude Desktop bundle include `skills/`.
- **Desktop bundles**: exclude development paths, node-gyp build output, and build-only package files.
- **Maintenance tooling and docs**: synchronize framework checks and development skills, simplify installation guidance, and consolidate bug-report environment fields.
- **Framework adoption**: Adopt mcp-ts-core 0.13.16 → 0.13.18: HTTP request cleanup from 0.13.17 and skill serving from 0.13.18.
- **Dependency age floor**: `minimumReleaseAge` moves from three days to one day.

## Fixed

- **Desktop skill loading**: preserve executable SDK `dist/ext/skills` modules while removing dependency package-root agent documentation ([cyanheads/mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794)).
