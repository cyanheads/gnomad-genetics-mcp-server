# 0.6.1 — 2026-11-25

## Added

- **`gnomad_list_gene_variants` `populations`**: opt-in input that appends `ac_<group>`, `an_<group>`, and `af_<group>` for each genetic-ancestry group of the dataset (10 on `gnomad_r4` and `gnomad_r3`, 8 on `gnomad_r2_1`, 7 on `exac`) to rows and the staged `gene_variants` table, after every other column. A group no summed callset lists is null, and `af_<group>` is null where `an_<group>` is 0 ([#81](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/81)).
- **`gnomad_list_gene_variants` `gene_id` and `gene_symbol`**: nullable columns on every row and the staged table, before `transcript_id`, naming the gene `consequence` is on. A region row reads gnomAD's per-row gene and carries null when it has no transcript consequence; `content[]` renders both ([#82](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/82)).
- **`User-Agent` on upstream requests**: every gnomAD and NCBI ClinVar request sends `gnomad-genetics-mcp-server/<version> (+https://github.com/cyanheads/gnomad-genetics-mcp-server)`.

## Changed

- **Tool definition text**: each tool states a caveat that spans fields (the FAF95 definition, the BA1/BS1 pointer, the QC rule, the dataset–build rule) in one description string instead of restating it per field, and a test caps each tool's server-authored bytes ([#83](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/83)).
- **Counters**: `gnomad.input.limit_clamped` and `gnomad.identifiers.normalized` are created once at module scope.
- **`gnomad-genetics-guide` skill 1.3**: adds the `populations` screen for an ancestry-specific carrier frequency.

## Fixed

- **Cancelled staging**: a `gnomad_list_gene_variants` or `gnomad_search_clinvar` call cancelled before its rows are staged no longer mints an empty canvas, which held a per-tenant canvas slot until its TTL expired.
