# 0.4.2 — 2026-10-24

## Changed

- **Upstream call budget** is fixed at 45 s across queue waits, retries, body reads, chained requests, and every item in a variant batch; work that previously ran longer now expires. Completed batch records survive, and caller cancellation rejects the call. ([#47](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/47))
- **DataCanvas** defaults to DuckDB for native installations; set `CANVAS_PROVIDER_TYPE=none` to disable it. The portable MCPB explicitly selects `none` because it excludes native bindings.
- **`gnomad_dataframe_query`** rejects bare `SELECT current_schema` as `denied_function` after the framework upgrade; it previously returned `main`. The parenthesized `current_schema()` form was already rejected; qualify a staged column with that name, such as `c.current_schema`.
- **Development tooling and docs** synchronize framework guidance and audit classification, refresh hosted-client setup examples, and move the Bun package-manager and Docker images from 1.4.3 to 1.4.4.

## Fixed

- **`gnomad_get_coverage`** reports `target_positions` and `missing_positions` beside observed `positions`, with notices for incomplete targets, missing supported tracks, and explicitly requested unsupported tracks; missing records leave callability unknown. The triage prompt carries the same guidance. ([#48](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/48))
- **Startup configuration** loads `.env` before tool definitions on Node and Bun, keeps exported settings authoritative, and validates complete settings inside setup with the clean configuration-error banner. Batch caps and drop-tool registration reflect file-only settings. ([#49](https://github.com/cyanheads/gnomad-genetics-mcp-server/issues/49))
- **Markdown output** preserves upstream text and SQL values as literal data while retaining raw values in structured output, including multiline labels and notices.
