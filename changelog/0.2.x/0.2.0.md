# 0.2.0 — 2026-08-21

## Added

- **Public hosted endpoint** — `https://gnomad-genetics.caseyjhand.com/mcp` is published as a Streamable HTTP remote in `server.json` and documented for installation-free use.
- **Boundary test suites** — smoke, integration, deterministic fuzz, and coverage lanes exercise the eight-tool surface, upstream response normalization, DataCanvas behavior, and unresolved correctness contracts.
- **Project community files** — citation, funding, security, contributing, and conduct guidance now ship with the repository.

## Changed

- **`@cyanheads/mcp-ts-core` `^0.10.10` → `^0.12.3`** — adopts MCP SDK v2 and protocol revision `2026-07-28`. Tool inputs now reject undeclared root keys, advertised output schemas include the error envelope, and callers that cache schemas should refresh `tools/list`.
- **Request context propagation** — gnomAD and ClinVar upstream calls pass the full handler context into framework request spans, preserving operation and correlation fields under the v2 context model.
- **Build and packaging** — Bun `1.3.14` → `1.4.0`, TypeScript `^6.0.3` → `^7.0.2`, test sources join the typecheck, Docker builds target the builder platform with cached script-free installs, and MCPB cleanup strips host-specific DuckDB bindings.
- **Supply-chain checks** — Socket's Bun scanner joins installs, the three-day release-age guard excludes first-party `mcp-ts-core`, dependency specifier checks cover overrides, and the outdated gate distinguishes installable updates from held releases.
- **Project tooling and agent guidance** — framework scripts, external skills, changelog conventions, package metadata, and contribution guidance are synchronized with `mcp-ts-core` `0.12.3`.
- **`@duckdb/node-api`** `^1.5.4-r.1` → `^1.5.5-r.4`.
